# sql-snippets

sql patterns i keep reusing. mostly postgres syntax but most of these work on any engine. adding stuff as i learn it.

## contents

- `window_functions/` — row_number, rank, running totals, moving averages
- `ctes/` — recursive ctes, chained transformations
- `date_utils/` — date spines, fiscal calendars, cohort bucketing
- `dedup/` — various dedup strategies
- `joins/` — anti joins, self joins, inequality joins
